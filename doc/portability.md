# Portability and ABI notes — 1.2 final

Scope: PL-03, PL-04 and the portability half of PL-08. Linux behaviour must
stay byte-identical; FreeBSD must compile with the libc and epoll-shim the C
build uses. All commands below were run on `ab5f4261`.

## Rules used

- Constants come from `std.posix` (or `std.os.linux` inside a Linux-only
  branch). No hard-coded Linux signal, open, fcntl, socket or permission
  numbers remain in the owned plumbing files.
- Signal masks and `sigaction` use `std.c.sigset_t` and `std.c.Sigaction`.
  That avoids a private mirror of an ABI whose layout differs between
  glibc, musl and FreeBSD.
- Only C declarations Zig does not expose (`TIOCSCTTY`, `_CS_PATH`,
  `struct utsname`/`uname`) are hand-written in `slave.zig` (per-platform
  constants) and `main.zig` (`extern` struct/functions). Zig 0.17.1 removed
  `@cImport`; keep these narrow hand-written declarations rather than
  translate-c output or generated bindings, and do not pull in headers such
  as `fcntl.h`.
- `struct termios` is mirrored locally for Linux (`Termios` in `slave.zig`).
  Zig 0.17's `std.c.termios` is the kernel UAPI layout (NCCS=19, 44 bytes),
  not glibc/musl's (NCCS=32, 60 bytes), so libc's `tcgetattr()`/`tcsetattr()`
  need the libc layout. A `comptime` assertion pins `@sizeOf(Termios) == 60`
  on Linux, and the pty round-trip in `tests/test-terminal.c` checks the
  behaviour.
- `errno` goes through `std.c._errno()`, which resolves to the target's libc
  accessor.

## epoll_event: native probe vs cross-derived constants

`fdm.zig` mirrors `struct epoll_event` as a packed struct on Linux
(`events`, `data` align(1)). Its size and both offsets are checked at
compile time against `c_layout.zig`, which is generated by the native C probe
in `abi_probe.c`. Measured on `ab5f4261` by
`rg -n 'EpollEvent' build/c_layout.zig`:
`EpollEvent__size = 12`, `EpollEvent_events = 0`, `EpollEvent_data = 4`.
The same probe is recorded in `abi_probe.c` (`sizeof(struct epoll_event)`
and `offsetof`), and `python3 scripts/gen_abi_probe.py --check` is clean.

On FreeBSD, epoll-shim follows the natural alignment of `epoll_data_t`;
`fdm.zig` uses `extern struct { events: u32, data: u64 }` with comptime
assertions of size **16** and `data` offset **8**. Those two numbers are
**cross-derived from the shim's C layout, not measured by a FreeBSD C probe**:
there are no FreeBSD headers in this container. The aarch64-linux-gnu build
reuses the packed Linux shape (12/4) and the same native-derived constants;
no aarch64 C probe runs here. `terminal_types.zig` carries the second mirror
of the Linux type and checks the same probe.

## Probe-backed config mirrors

Eight config-side element types that previously had no `expectAbi()`
(`ConfigFont`, `ConfigFontList`, `ConfigSpawnTemplate`, `Argv`,
`BindingAux`, `ConfigKeyBinding`, `ConfigKeyBindingList`, `CustomRegex`)
are pinned directly (`rg -n 'expectAbi\(' terminal_types.zig`). `expectAbi()`
recurses into fixed arrays of value-typed mirrors, so `Config.fonts[4]`,
`Terminal.notification_icons[32]`, `KeySet.vmods[8]`,
`WlWindow.csd.surface[]` and `Vt.params.v[16]` check their element layouts,
not just the array byte size. The `tll(struct seat)` node/list shape is probed
as `SeatNode`/`SeatList` and checked against both Zig node mirrors.

Remaining accepted gaps: pointer-reached element types rely on direct
`expectAbi` rather than recursive probing, and the tll node is probed only via
the seat instantiation; FreeBSD's epoll-shim layout and constants remain
target-only claims.

Other layout handling:

- `terminal_types.zig`: `sockaddr_un.sun_path` is 108 bytes on Linux and 104 on FreeBSD;
  the native C probe checks the selected layout, the cross check compiles but
  does not link C.
- `server.zig`: FreeBSD has no `SOCK_CLOEXEC`/`SOCK_NONBLOCK` open flags;
  the socket is created plain and the flags are applied with `fcntl()`.
- `client.zig` `Stat`: the glibc x86_64 layout stays as `LinuxStat`, probed
  and checked locally; other targets use `std.c.Stat`. `sockaddr_un` and
  `Passwd` use `std.c` types; `terminal.zig` uses
  `std.c.Sigaction`/`std.c.sigset_t`.

## Gate and what it proves

    debug build:     ninja -C build && meson test -C build
    disabled build:  ninja -C build-disabled && meson test -C build-disabled
    release build:   ninja -C build-release && meson test -C build-release
    ABI probe:       python3 scripts/gen_abi_probe.py --check
    cross targets:   sh scripts/check-targets.sh

`sh scripts/check-targets.sh` was run on `ab5f4261`: exit 0, **10
combinations, 0 SKIP** — `x86_64-freebsd` and `aarch64-linux-gnu`, each with
`fdm.zig`, `spawn.zig`, `slave.zig`, `main.zig` and `server.zig`.
It invokes `zig build-obj -fno-emit-bin` with a native `c_layout.zig`, so
**these are compile-only claims**: no FreeBSD or aarch64 C probe is linked or
run, no FreeBSD headers are present, and no runtime behaviour is verified on
those targets.

| Claim | Status | Evidence / limit |
|---|---|---|
| Native Linux `epoll_event` 12/4 matches C | verified | `abi_probe.c` probe, `build/c_layout.zig` constants, `gen_abi_probe.py --check` clean, `meson test` 9/9 |
| FreeBSD cross compile of five files | verified (compile-only) | `scripts/check-targets.sh` exit 0, 10 combinations / 0 SKIP; `-fno-emit-bin` |
| aarch64 cross compile of five files | verified (compile-only) | same command; no aarch64 C probe |
| FreeBSD epoll-shim 16/8 | cross-derived | comptime asserts in `fdm.zig`; no FreeBSD headers here |
| FreeBSD epoll-shim API constants | unverified | explicit Linux-compatible values in `server.zig`/`fdm.zig`; no FreeBSD C header check |
| Eight config element mirrors and array recursion | verified | direct `expectAbi` calls and array recursion in `terminal_types.zig`; native probe check clean |
| Pointer-reached element types, seat tll node | accepted gap | direct `expectAbi` only; node probed only via the seat instantiation |
